## CSV to Markdown Converter

複数のテーブルが1つにまとまったCSV（Excel方眼紙っぽい形式）を、セクションごとのMarkdown表に変換するツールです。BOM付きUTF-8を安全に扱い、空行や単独セルの見出しを解釈してMarkdownを生成します。

### 主な仕様
- 空行でテーブルを区切り、単独セルの行を見出し（`### 見出し`）として出力
- 1列目が全て空のテーブルは1列目を自動で削除（Excel方眼対策）
- 列数が揃わない行はヘッダーに合わせて欠損を埋める／余分を切り詰め
- 改行は `<br>` に変換してMarkdown崩れを防止
- 出力先は実行ファイル（またはスクリプト）と同じディレクトリ配下の `Converts/`

### 実行方法
	- `main.exe` に CSV をドラッグ＆ドロップするだけ
	- `Converts/` フォルダに Markdown (`.md`) が生成されます

### おまけ: Pythonスクリプトとして実行
依存を入れて直接叩く場合（デバッグや動作確認用）:
```bash
pip install markitdown
python main.py DBtable.csv
```
出力は同じく `Converts/DBtable.md` に保存されます。

### CSV入力の想定フォーマット
- テーブル間は完全な空行で区切る
- 見出し行は有効なセルが1つだけの行（例: `,,,基本情報,,,,`）
- テーブルの1行目がヘッダーとして扱われ、空のヘッダーは空白で埋められます

### トラブルシュート
- 文字化けする場合: 入力CSVをUTF-8(BOM付き可)で保存してください
- 変換結果がおかしい場合: 空行の位置と見出し行（単独セル行）が正しく入っているか確認してください
